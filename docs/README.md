Detailed migration, hotfix and milestone records remain part of the repository history. They are intentionally not duplicated in the public README.

The project may later consolidate those records under `docs/history/`; the R5c7 release manifest currently preserves their validated paths, so that reorganization should be handled deliberately rather than by a documentation-only patch.
