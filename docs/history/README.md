# Development history

The repository contains detailed migration, hotfix, validation and milestone documents accumulated during development.

They are intentionally not moved by the current GitHub-presentation patch because the validated R5c7 `SOURCE_MANIFEST.json` records their existing paths. Moving them without deliberately updating the release-manifest strategy would make the current source verification contract ambiguous.

A future repository-structure pass can consolidate those documents here once the project decides whether release manifests remain immutable snapshots, versioned per tag, or are regenerated for post-release documentation commits.
