# RP-R4b Validation

1. Extract the archive to a new folder.
2. Run `run_windows.cmd` normally, not as Administrator.
3. Confirm setup prints that dependencies are installed without the global pip cache.
4. Confirm `Installed Rubra Packager: 0.4.2`.
5. Confirm the automated tests pass.
6. Confirm the UI opens.
7. Close and reopen the launcher; setup must not repeat.
8. Run an Arena Rubra FULL preflight and one EXE or APK build.
