INDEPENDENT PUBLIC BASELINE

Rubra Packager RP-R4

This repository focuses on reproducible packaging of trusted offline web games. It uses its own project registry, profile format, interface and modular build engine.

The current public scope is deliberately narrow: Windows one-file executables and Android debug APKs. Python-to-EXE, visual templates and broad framework source rewriting are not part of this project.

Only run npm build steps for projects you trust. Package scripts can execute code on your computer.
